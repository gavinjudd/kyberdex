More than a collection counter.

A full community game loop, with deliberate protections around the cards people earn.

02 / THE ENGINE

The rules are in the repo.

Small enough to understand. Explicit about state, ownership and what happens when a process restarts.

DURABLE STATESQLite · WAL · atomic transactions
SEPARATE READ PATHPublic catalog → definitions + reviewed assetsNo player databases. No mutation endpoints.

Ownership has a commit point.

Captures, stock reservations, crafting and trades enforce their rules in database transactions. Replayed interactions do not become duplicate rewards.

Schedules survive restarts.

Sampled deadlines and activity contributions are persisted. Quiet periods stay quiet, even when a timer is overdue.

Operations are part of the source.

Offline readiness checks, integrity-checked paired backups, restore validation and systemd examples ship with the engine.

Presentation has its own layer.

Pillow composes six rarity finishes from reviewed assets. Rendering runs outside the Discord gateway loop with a bounded cache.

04 / GET STARTED

One command. A guided setup.

Install into ~/kyberdex on your computer or server. The wizard handles local tools, configuration, artwork and readiness.

INSTALL KYBERDEXLINUX / macOS / WSL
curl -fsSL https://raw.githubusercontent.com/gavinjudd/kyberdex/main/install.sh | sh

Installs uv and Python when needed. No sudo or shell-profile changes. The first artwork download is about 175 MB; retries reuse the cache.

Read the installer · Manual setup

Your bot. Your server.

Discord requires you to create a bot and authorize its server invite in your browser. The wizard points you to those steps, then continues locally.

  1. Enter your bot token in the hidden local prompt.
  2. Choose your server and public text channels.
  3. Let artwork setup and readiness checks finish.
  4. Start the bot in the foreground when prompted.

Keep the terminal open while it runs; Ctrl+C stops it. Restart with cd ~/kyberdex && ./start.sh. One guild per deployment.

05 / GOOD TO KNOW

A few things, up front.

What does the one-command installer do?

The installer prepares the local tools and KyberDex, then opens a guided setup for your bot token, server and channels. It installs artwork, checks readiness and offers to start the bot. You still create the Discord bot and authorize its server invite in your browser. Read the setup guide.

Is KyberDex free and open source?

The original software is MIT licensed. You host and operate your own instance. Third-party fonts have their own notices; the code license does not grant rights to Star Wars characters, trademarks or third-party artwork. Read the licensing boundaries.

Does KyberDex use paid card packs?

No. The game has free daily credits, captures, a credit-based market and crafting. It has no real-money purchases, paid randomness or card wagers.

Can one deployment serve many Discord servers?

The current release is designed for one configured guild and one active game worker. It is not a multi-tenant hosted bot platform. See the operating limits.
